**启动方式：**
- H2（开发）：`.\mvnw.cmd spring-boot:run`（默认）
- MySQL（部署）：`.\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=mysql`

**关键差异：**
- MySQL schema 使用 `UNIQUE KEY uk_xxx (...)` 替代 `UNIQUE (...)` 
- MySQL 时间函数：`DATE_ADD(NOW(), INTERVAL 14 DAY)` 替代 `DATEADD('DAY', 14, NOW())`
- MySQL 插入使用 `INSERT IGNORE` 防止重复执行报错

## Vue 前端 — 登录跳转修复 + 管理端菜单合并

### 问题诊断
admin 登录后始终显示学生端，根因是 **Axios 响应拦截器未剥离后端 `{ code, data }` 包装层**，导致 `res.data` 拿到的始终是 `{ code: 200, data: {...} }`，`res.data.role` 为 `undefined`，LoginView 的角色判断永远走 else 分支。

### 修复
**`src/api/http.ts`** — 响应拦截器加一行 `response.data = body.data`，统一剥离包装层，此后所有 API 调用方 `res.data` 直接拿到业务数据。

### 管理端菜单合并
- admin 侧边栏合并教师端 4 项（教学概览/任务管理/实验记录/数据统计）+ 系统管理 3 项（用户管理/班级管理/阈值模板），中间用分隔线
- admin 登录默认进教学概览
- 路由守卫：ADMIN 角色可访问所有 `/teacher/*` 和 `/admin/*` 路由

### 登录跳转
- LoginView 使用 `window.location.href` 硬跳转替代 `router.push`，绕过 Vue Router redirect 的潜在时序问题
- 路由 `/` redirect 改为函数：读 localStorage user_role，admin/teacher → `/teacher/dashboard`，student → `/student/dashboard`
- MainLayout 角色检测增加 `localStorage.getItem('user_role')` 兜底
