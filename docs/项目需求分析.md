## 1. 引言

### 1.1 项目背景

水硬度测定是大学《分析化学实验》中的基础实验，常用方法为 EDTA 络合滴定法。实验过程中，水样加入铬黑 T 指示剂后通常呈酒红色，随着 EDTA 标准溶液滴入，溶液逐渐由酒红色向蓝紫色、纯蓝色变化。当溶液达到稳定纯蓝色且短时间内无明显返色时，可作为滴定终点判断依据。

传统教学实验中，滴定终点主要依靠学生或教师肉眼观察颜色变化。该方式受环境光照、容器反光、观察角度、个人经验和色彩分辨能力影响较大，容易出现提前停止、滴定过量或终点误判，导致实验结果误差较大，学生之间数据重复性较差。

同时，高校实验教学不仅需要完成单次实验检测，还需要管理学生、教师、实验任务、实验记录、批注评分和实验数据归档。因此，本项目不再定位为单一桌面检测工具，而是建设一套由 Web 教学管理平台、Java 后端服务和 Python 本地视觉检测端组成的综合系统。

### 1.2 项目目的

1. 使用计算机视觉方法辅助识别 EDTA 水硬度滴定过程中的颜色变化，降低人工判色主观误差。
2. 根据纯蓝色稳定时长自动辅助判断滴定终点，提高实验结果的准确性和可复核性。
3. 建立学生、教师、管理员三类角色体系，实现实验任务、实验记录、批注评分和数据统计管理。
4. 将检测端产生的终点结果、HSV 参数、关键帧和实验日志上传至平台，方便教学复盘。
5. 形成一个既具备计算机视觉特色，又具备完整教学管理业务的毕业设计系统。

### 1.3 适用范围

本系统适用于：

- 高校分析化学实验教学；
- EDTA 络合滴定法测定水的总硬度；
- 铬黑 T 指示剂体系；
- 使用无色透明锥形瓶或烧杯的滴定实验；
- 学生实验过程记录、教师批阅评分、管理员统一维护；
- 普通实验室电脑、USB 摄像头或内置摄像头环境。

### 1.4 不适用范围

本系统暂不适用于：

- 非铬黑 T 指示剂体系；
- 其他水质检测实验或其他类型滴定实验；
- 有色、磨砂、严重反光容器；
- 极端强光、全黑、彩色光源照射等异常光照环境；
- 自动控制滴定设备或自动读取滴定管刻度；
- 仅凭图像精确计算 EDTA 过量体积。

## 2. 系统总体说明

### 2.1 系统定位

本系统是一套面向高校实验教学场景的“教学管理 + 视觉检测”综合平台。

系统由三部分组成：

| 子系统 | 主要职责 |
| --- | --- |
| Vue Web 前端 | 提供学生端、教师端、管理员端操作界面 |
| Java 后端服务 | 提供登录认证、权限控制、任务管理、实验记录、批注评分、文件上传和统计接口 |
| Python 检测端 | 完成摄像头采集、ROI 框选、颜色识别、终点判定和检测结果上传 |

### 2.2 系统架构

```text
学生 / 教师 / 管理员
        ↓ 浏览器访问
Vue 3 教学管理平台
        ↓ HTTP API
Java Spring Boot 后端
        ↓
MySQL 数据库 + 文件存储
        ↑
Python 本地视觉检测端
        ↑
摄像头采集滴定实验画面
```

### 2.3 用户角色

| 角色 | 说明 | 主要需求 |
| --- | --- | --- |
| 学生 | 实验执行者 | 查看任务、启动检测端、完成实验、查看结果和教师反馈 |
| 教师 | 实验指导与评价者 | 发布任务、查看学生记录、批注评分、查看统计 |
| 管理员 | 系统维护者 | 管理用户、班级、角色、阈值模板和系统配置 |

### 2.4 业务流程

```text
管理员创建用户和班级
        ↓
教师发布实验任务
        ↓
学生登录平台查看任务
        ↓
学生启动 Python 检测端
        ↓
检测端完成摄像头采集、ROI 框选和终点识别
        ↓
检测端上传实验结果、HSV 数据、关键帧和日志
        ↓
教师查看记录并批注评分
        ↓
学生查看评分和反馈
        ↓
平台生成实验统计数据
```

## 3. 实验原理与检测目标

### 3.1 颜色变化原理

| 阶段 | 实验现象 | 系统识别状态 |
| --- | --- | --- |
| 初始阶段 | 水样与铬黑 T 指示剂结合后呈酒红色或玫瑰红色 | 初始色 |
| 滴定阶段 | 随 EDTA 滴入，红色逐渐减弱并转为紫蓝色 | 滴定中 / 临近终点 |
| 候选终点 | 溶液达到预设纯蓝色阈值 | 候选终点 |
| 有效终点 | 纯蓝色连续稳定默认 30 秒，无明显返色 | 滴定终点 |
| 终点后继续滴定 | 终点已确认但仍继续操作 | 终点后提醒 |

### 3.2 检测目标

1. 实时采集滴定容器内溶液画面。
2. 支持用户框选 ROI，仅分析溶液主体区域。
3. 对 ROI 图像进行去噪、光照处理和 HSV 色彩空间转换。
4. 区分酒红色、蓝紫色过渡色和纯蓝色。
5. 对纯蓝色进行默认 30 秒稳定性验证。
6. 输出终点判定结果、匹配度、HSV 参数、关键帧和实验日志。
7. 将检测结果上传至 Java 后端，形成可查询、可批阅、可统计的实验记录。

### 3.3 检测端状态机

| 状态 | 说明 |
| --- | --- |
| 待机 | 程序启动，等待用户登录和选择实验任务 |
| 采集准备 | 摄像头已连接，等待框选 ROI 和确认参数 |
| 初始色 | 当前颜色匹配酒红色或玫瑰红色 |
| 滴定中 | 颜色持续变化，未达到终点色 |
| 临近终点 | 颜色进入紫蓝色或过渡蓝区域 |
| 候选终点 | 检测到纯蓝色，开始稳定计时 |
| 有效终点 | 纯蓝色稳定达到默认 30 秒 |
| 暂停 | 用户暂停或采集异常 |
| 异常 | 摄像头、画面、网络、存储或算法出现异常 |

## 7. 异常处理需求

| 编号 | 异常场景 | 处理方式 |
| --- | --- | --- |
| ERR-01 | 摄像头未连接 | 检测端提示连接摄像头，禁止开始检测 |
| ERR-02 | 摄像头中途断开 | 暂停检测，保留已采集数据 |
| ERR-03 | 画面黑屏、遮挡或过曝 | 暂停终点计时，提示调整环境 |
| ERR-04 | 颜色异常突变 | 记录异常事件，提示检查试剂和光照 |
| ERR-05 | 网络异常 | 检测端本地缓存结果，网络恢复后补传 |
| ERR-06 | Token 失效 | 前端或检测端提示重新登录 |
| ERR-07 | 文件上传失败 | 保留本地文件，允许重新上传 |
| ERR-08 | 无权限访问 | 后端拒绝请求并返回权限错误 |
| ERR-09 | 数据库写入失败 | 后端记录日志并返回明确错误信息 |

## 8. 系统约束与边界

1. 系统仅适配铬黑 T 指示剂体系下的 EDTA 水硬度滴定实验。
2. 检测端不控制滴定设备，不自动读取滴定管刻度。
3. 系统可辅助判断滴定终点，但最终实验结果仍需符合教师和实验规范要求。
4. 颜色识别依赖摄像头、光照和容器条件，异常环境会降低准确性。
5. 终点后继续滴定只能提示风险，不能仅凭颜色图像精确计算过量体积。
6. 首期文件存储采用服务器本地目录，后续可扩展为对象存储。
