# 水硬度滴定图片识别 Demo 说明

## 1. Demo 目标

本 Demo 用于两天内向老师展示项目核心可行性：通过上传一张滴定实验图片，系统自动分析图片中心区域颜色，并判断当前滴定状态。

当前 Demo 暂不做实时摄像头识别，先完成静态图片识别闭环。

## 2. 已实现能力

1. 上传滴定实验图片；
2. 自动选取图片中心区域作为 ROI；
3. 提取 ROI 的 RGB 像素并转换为 HSV；
4. 统计酒红色、蓝紫色、纯蓝色像素占比；
5. 输出识别状态：
   - 滴定进行中；
   - 临近终点；
   - 滴定终点；
   - 颜色异常；
6. 展示 H、S、V 参数、颜色占比和匹配度；
7. 在学生端首页中展示识别结果。

## 3. 演示步骤

在 `front` 目录运行：

```powershell
npm.cmd run dev
```

打开终端提示的本地地址，一般为：

```text
http://localhost:5173
```

演示流程：

1. 打开学生端页面；
2. 找到“滴定图片颜色识别”模块；
3. 点击“上传滴定图片”；
4. 选择一张滴定溶液图片；
5. 查看系统输出的颜色状态、匹配度、HSV 参数和颜色占比；
6. 说明当前为图片识别原型，后续会接入 Python OpenCV 实时摄像头检测。

## 4. 演示话术

可以这样向老师说明：

> 当前版本先完成了静态图片识别 Demo。系统会读取滴定图片中心 ROI 区域，提取 HSV 颜色特征，并根据铬黑 T 滴定实验的酒红色、蓝紫色、纯蓝色变化规律进行状态判断。后续版本会将同一套颜色识别逻辑迁移到 Python OpenCV 检测端，实现摄像头实时识别和 30 秒稳定终点判断。

## 5. 当前限制

1. 当前只识别图片，不识别实时视频；
2. 当前 ROI 为图片中心自动区域，暂未支持手动框选；
3. 当前阈值为前端内置经验阈值，需要后续结合真实实验图片校准；
4. 当前识别结果用于 Demo 展示，不作为正式实验判定结果；
5. 后续正式版应由 Python 检测端完成实时识别，并上传结果到 Java 后端。

## 6. 两天内建议补充

如果时间允许，建议准备 3 类图片用于演示：

1. 酒红色图片：展示“滴定进行中”；
2. 蓝紫色图片：展示“临近终点”；
3. 纯蓝色图片：展示“滴定终点”。

这样老师能直观看到系统可以区分不同滴定阶段。
