## 3. API 接口清单

### 3.1 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| code | 含义 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未认证 / Token 失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 3.2 认证接口

#### POST /api/auth/login — 用户登录

**Request:**
```json
{
  "username": "student01",
  "password": "123456"
}
```

**Response:**
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userId": 3,
    "username": "student01",
    "realName": "张同学",
    "role": "STUDENT",
    "tokenType": "Bearer",
    "expiresIn": 86400000
  }
}
```

#### GET /api/auth/me — 获取当前用户信息

**Headers:** `Authorization: Bearer <token>`

**Response:**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 3,
    "username": "student01",
    "realName": "张同学",
    "role": "STUDENT",
    "status": "ENABLED",
    "classId": 1,
    "email": "student01@example.com"
  }
}
```

### 3.3 实验任务接口

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | `/api/tasks` | 任务列表（分页） | 登录用户 |
| GET | `/api/tasks/{id}` | 任务详情 | 登录用户 |
| POST | `/api/tasks` | 创建任务 | TEACHER / ADMIN |
| PUT | `/api/tasks/{id}` | 更新任务 | TEACHER / ADMIN |
| POST   | `/api/tasks/{id}/assign` | 分配任务给学生 | TEACHER / ADMIN |
| GET    | `/api/tasks/{id}/assignments` | 查看任务分配情况 | 登录用户 |

**GET /api/tasks 查询参数：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| page | int | 页码，默认 1 |
| size | int | 每页条数，默认 10 |
| status | String | 筛选状态：DRAFT / PUBLISHED / CLOSED |

> 学生角色自动过滤只显示 `PUBLISHED` 状态的任务。

## 5. 配置说明

### 5.1 数据库双模式

| 模式 | Profile | 数据库 | 启动命令 |
| --- | --- | --- | --- |
| 开发（默认） | 无 | H2 内存数据库 | `.\mvnw.cmd spring-boot:run` |
| 生产 | mysql | MySQL 8 | `.\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=mysql` |

### 5.2 application.yml 关键配置（H2 默认）

```yaml
server:
  port: 8080

spring:
  datasource:
    driver-class-name: org.h2.Driver
    url: jdbc:h2:mem:titration_detection;MODE=MySQL
  h2:
    console:
      enabled: true
      path: /h2-console
  sql:
    init:
      mode: always
      schema-locations: classpath:schema.sql
      data-locations: classpath:data.sql

jwt:
  secret: titration-detection-system-jwt-secret-key-2026-graduation-project
  expiration: 86400000      # 24 小时

file:
  storage:
    root-path: ./storage    # 文件存储根目录
```

### 5.3 application-mysql.yml 关键配置

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/titration_detection?...&createDatabaseIfNotExist=true
    username: root
    password: root          # 部署时修改
  sql:
    init:
      schema-locations: classpath:schema-mysql.sql
      data-locations: classpath:data-mysql.sql
```
