| 项目 | 内容 |

| 文档版本 | V1.0 |

| 排序规则 | utf8mb4_0900_ai_ci |

---

## 1. 设计目标

本数据库用于支撑“Vue 前端 + Java Spring Boot 后端 + Python 检测端”的正式系统开发。第一阶段重点实现以下闭环：

```text
学生登录
  ↓
查看实验任务
  ↓
上传或识别滴定图片
  ↓
保存实验记录
  ↓
教师查看记录并批注评分
```

数据库设计兼顾当前图片识别 Demo 和后续实时摄像头检测端扩展。

---

## 2. 核心实体关系

```text
classes 1 --- n users
users 1 --- 1 student_profiles
users 1 --- 1 teacher_profiles
users 1 --- n experiment_tasks
experiment_tasks 1 --- n task_assignments
experiment_tasks 1 --- n experiments
users 1 --- n experiments
experiments 1 --- n color_samples
experiments 1 --- n state_events
experiments 1 --- n experiment_files
experiments 1 --- 1 reviews
threshold_templates 1 --- n experiments
```

## 5. 状态枚举建议

### 5.1 用户角色 role

| 值 | 含义 |
| --- | --- |
| STUDENT | 学生 |
| TEACHER | 教师 |
| ADMIN | 管理员 |

### 5.2 识别状态 recognition_status

| 值 | 页面显示 | 含义 |
| --- | --- | --- |
| IN_PROGRESS | 滴定进行中 | 酒红色或玫瑰红色为主 |
| NEAR_ENDPOINT | 临近终点 | 蓝紫色或过渡色为主 |
| ENDPOINT | 滴定终点 | 纯蓝色为主 |
| ABNORMAL | 颜色异常 | 未匹配典型颜色 |

### 5.3 匹配颜色 matched_color

| 值 | 含义 |
| --- | --- |
| RED | 酒红色 |
| PURPLE | 蓝紫色 |
| BLUE | 纯蓝色 |
| UNKNOWN | 未知颜色 |

### 5.4 检测模式 detect_mode

| 值 | 含义 |
| --- | --- |
| IMAGE | 图片识别 |
| VIDEO | 视频识别 |
| CAMERA | 摄像头实时识别 |

### 5.5 提交状态 submit_status

| 值 | 含义 |
| --- | --- |
| DRAFT | 草稿 |
| SUBMITTED | 已提交 |
| REVIEWED | 已批阅 |

## 8. 开发建议

1. 第一阶段先实现 `users`、`experiment_tasks`、`experiments`、`experiment_files`、`reviews`。
2. 图片识别 Demo 的结果可直接写入 `experiments`。
3. 上传的原图保存到 `experiment_files`，`file_type` 使用 `SOURCE_IMAGE`。
4. 后续 Python 实时检测端可批量写入 `color_samples` 和 `state_events`。
5. 教师批阅后，应同步将 `experiments.submit_status` 更新为 `REVIEWED`。
